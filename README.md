# 🌊 LangChain + RAG Learning Experiments

Welcome! 👋  
This repository is my **personal learning lab** for exploring **LangChain**, **RAG (Retrieval-Augmented Generation)**, and **foundational Machine Learning concepts**.  

I’m on a journey to understand **how LLM pipelines work under the hood** before building complete systems.  

---

## 🔹 What I’m Exploring

- **LangChain Fundamentals**  
  Chains, prompts, memory management, and structured LLM outputs  

- **Prompt Chaining & Output Parsing**  
  Designing multi-step reasoning pipelines with predictable outputs  

- **ChatPromptTemplates**  
  Controlled, reusable prompt design for consistent LLM responses  

- **RAG Workflows**  
  Embeddings, vector stores, similarity search, and retrieval-based generation  

- **Machine Learning Foundations**  
  Embeddings (mathematical & intuitive), NumPy, Pandas, scikit-learn  
  Connecting classical ML concepts with modern LLM applications
